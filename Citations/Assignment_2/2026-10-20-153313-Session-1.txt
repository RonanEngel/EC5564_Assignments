  q1.ipynb (Assignment_2/q1.ipynb) is a binary classification problem. Each

  q2.ipynb (Assignment_2/q2.ipynb) so far only has the instructor's starter code
  (hw2q2, generateData, generateDataFromGMM, plot3). It builds a 3-component
  mixture where x1 and x2 are inputs and the third dimension is the target y.
  There are 100 training samples and 1000 validation samples. Nothing of yours
  is in it yet.

  While reading q1, I noticed a few problems you'll probably hit:

  1. Priors applied in the wrong place (ERM cell): (.5*g01) + (.5*g02) * prior_0
     multiplies only the second component by the prior. It should be (.5*g01 +
     .5*g02) * prior_0, and the same for class 1. This means the 0.7126 accuracy
     is probably wrong.
  2. Threshold value: for a ratio p(x|1)/p(x|0), the minimum-error threshold is
     prior_0 / prior_1 = 1.5, not prior_1 / prior_0.
  3. ROC cell won't run as written:
     - scores has two columns (N, 2). It needs to be a single log-likelihood
       ratio per sample, log p(x|1) − log p(x|0), before you sort it into
       thresholds.
     - Gamma_map uses L, which doesn't exist. It should be L_10000.
  4. q2's plot3: Axes3D(fig) shows a blank plot in recent matplotlib versions.
     Use ax = fig.add_subplot(projection='3d') instead.
